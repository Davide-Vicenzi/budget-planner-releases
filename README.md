# Budget Planner — installer

Qui si trovano solo gli **installer per Windows** di Budget Planner, l'app per pianificare il budget personale e familiare anno per anno.

- Il codice sorgente è privato.
- Per usare l'app serve un file di licenza (`.lic`).
- Le app installate si aggiornano da sole a partire dalle release di questa pagina.
